## 2. 八层能力架构

```text
L1 任务    L2 飞控    L3 导航    L4 链路
L5 载荷    L6 数据    L7 风控    L8 复盘
```

### L1 任务（Mission）

| 战争侧工程习惯（抽象） | 商业精密场景 | 商业关键能力 | Tokfai 可做 |
| ---------------------- | ------------ | ------------ | ----------- |
| 任务分解、时序、约束 | 电力巡检航线、矿山测绘块、物流点对点 | 任务边界清晰、可重复、可审计 | 解析任务计划 PDF/Word；输出边界四象限（[37](./37-rejection-to-evidence-remediation-chain.md)） |
| 多机协同编排 | 应急编队、大面积测绘 | 冲突检测、空域/时间窗 | 任务表 vs 申请栏位对照；**不规划非法空域** |

**商业场景：** 巡检 / 测绘 / 电力 / 水利 / 矿山 / 农林 / 应急 / 低空物流 — 均需**书面任务+批准范围**内作业。

### L2 飞控（Flight Control）

| 抽象能力 | 商业场景 | 证据常见位置 | Tokfai 可做 |
| -------- | -------- | ------------ | ----------- |
| 姿态/轨迹稳定 | 风电叶片巡检、精密测绘 | ControlLaw、模式切换 | 固定四文件链：入口→律→分配→执行器（教学/授权代码） |
| 降级/保护 | 物流、农林喷洒 | FDIR、限功率 | 函数级指针；不宣称适航 |

### L3 导航（Navigation）

| 抽象能力 | 商业场景 | 证据 | Tokfai 可做 |
| -------- | -------- | ---- | ----------- |
| GNSS/惯导融合 | 测绘、电力 corridor | 导航模块 `.c`、ICD | 路径+接口名；对照任务航线文件 |
| 返航/备降点 | 应急、偏远矿山 | 手册应急节 | EVIDENCE_ROW 指针 |

### L4 链路（C2 / Datalink）

| 抽象能力 | 商业场景 | 证据 | Tokfai 可做 |
| -------- | -------- | ---- | ----------- |
| 链路监控、丢链处置 | 超视距物流、水利长距离 | 通信栈、地面站日志 | 异常码↔手册字段；**不破解链路** |
| 动态数据/识别字段 | 合规报送 | UOM 手册、ICD | 栏位↔模块路径 |

### L5 载荷（Payload）

| 抽象能力 | 商业场景 | 证据 | Tokfai 可做 |
| -------- | -------- | ---- | ----------- |
| 传感器/相机/喷洒协同 | 测绘、农林、电力红外 | 载荷驱动、云台协议 | 调用链指针；载荷模式与任务一致性 |
| 时点/位置触发 | 测绘拼图 | 任务脚本 | 日志时间点↔任务书 |

### L6 数据（Data）

| 抽象能力 | 商业场景 | 证据 | Tokfai 可做 |
| -------- | -------- | ---- | ----------- |
| 飞参/状态记录 | 全场景验收 | `.ulg`/自研日志 | 本机解析摘要；异常段指针 |
| 影像/点云元数据 | 测绘交付 | 文件夹结构、POS | 飞后清单；不替代质检 |

### L7 风控（Risk / Compliance）

| 抽象能力 | 商业场景 | 证据 | Tokfai 可做 |
| -------- | -------- | ---- | ----------- |
| 运行前检查 | 政企项目 | SOP、检查单 | 步骤↔手册一致性 |
| 材料/准入 | 首次飞行 | 申请、退回意见 | 驳回诊断（[36–38](./36-approval-rejection-diagnosis-map.md)） |

### L8 复盘（Post-mission）

| 抽象能力 | 商业场景 | 证据 | Tokfai 可做 |
| -------- | -------- | ---- | ----------- |
| 任务完成度、异常归因 | 电力/矿山客户验收 | 日志+报告 | 时间线+函数/模式线索（ADVICE） |
| 知识沉淀 | 机队运维 | 工单历史 | 本机知识库问答（[26](./26-ai-workflow-for-aviation-customers.md)） |

## 3. 商业场景 × 八层权重（交付优先级）

| 场景 | 强依赖层 | 典型客户文件 |
| ---- | -------- | ------------ |
| 电力巡检 | L1 L2 L5 L8 | 任务书、航线、红外载荷说明、日志 |
| 测绘 | L1 L3 L5 L6 | 区块设计、POS、相机校准、成果规范 |
| 水利/河道 | L1 L3 L4 L7 | 空域申请、远距离链路、应急 |
| 矿山 | L3 L7 L8 | 场地许可、GNSS 环境、复盘 |
| 农林 | L2 L5 L7 | 喷洒控制、手册、作业记录 |
| 应急 | L4 L7 L8 | 协调函、链路、日志 |
| 低空物流 | L2 L3 L4 L7 | 运营规范、C2、动态数据 ICD |
| 通用政企 | L7 L1 | 申请材料、任务边界 |

Tokfai 进场：**先 L7+L1（能合法飞、边界清楚）**，再 L2/L3/L4 证据链，最后 L8。

## 4. 战争→商业能力对照表（非武器）

| 工程能力域 | 商业精密表达 | 明确排除 |
| ---------- | ------------ | -------- |
| 任务规划 | 合法任务书、航线、时段 | 打击任务、未授权空域 |
| 飞控稳定 | 姿态/轨迹 hold、风扰抑制 | 末端机动攻击 |
| 导航定位 | RTK/惯导、航点跟踪 | 对地武器瞄准 |
| 链路可靠 | 丢链返航、冗余 | 抗干扰攻击用途 |
| 载荷协同 | 相机/雷达/喷洒触发 | 武器发射链 |
| 异常处置 | RTH、迫降、模式降级 | 伤害最大化策略 |
| 数据记录 | 飞参、影像元数据 | 目标识别打击库 |
| 复盘 | 架次报告、缺陷单 | 战损评估 |

## 5. Tokfai 立场

```text
不做武器化、不做非法飞行、不教规避监管
不做：上控飞、代报 UOM、保证审批
只做：证据链、文件理解、任务规划辅助（在客户文件内）、日志复盘、交付报告
客户敏感文件不出站；Codex CLI 本机读；Tokfai 路由/计费/日志
```
