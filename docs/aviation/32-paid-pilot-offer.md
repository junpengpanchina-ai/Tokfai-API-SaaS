## A. 轻量验证版

**适合：** 培训学校、首次接触的整机厂/飞控组、运营商“先看方法”、认证辅导联合对客户预演。温度=热，尚未书面授权客户源码。

**交付**

- 协助本机安装 old Codex CLI、连上 Tokfai（环境变量放 key，不写入仓库）
- 一次 **synthetic** 四文件链陪跑（可复用演示）
- 一页使用边界说明（本机工具 vs 网关）
- 用量包：合同写明请求/额度上限（建议按 2 周验证够用）
- 开通陪跑：最多 **4 小时** 远程（安装+答疑）

**不交付**

- 不读客户仓库（除非客户自己投屏且仍算演示范围外的自愿，**默认不包含**）
- 不出适航意见、不改飞控代码、不写投标技术方案
- 不保证某模型一定出 tool_calls（按 SOP 推荐 `gemini-3-pro`）

**周期：** 5–10 个工作日（含客户 IT 装软件等待）。

**验收标准**

1. CLI 能连上 Tokfai（由客户确认，不展示密钥）  
2. 教学树上完成分段链：`attitude_control_entry` → `rotor_law_update` → `control_allocation` → `actuator_command_write`  
3. 至少一段有 Read 工具记录  
4. 客户书面确认理解：Tokfai 不执行本机工具、不托管源码  

**客户提供：** 一台可联网电脑、一位愿意装 CLI 的人、会议时间。  
**Tokfai 提供：** 账号/用量包、安装说明、教学树路径、陪跑小时。

**风险边界：** 客户内网装不了 CLI → 可取消转全额或只完成屏幕共享教学（合同勾选项）。不承担客户 IT 策略后果。

**建议报价：** ¥8,000–18,000。  
**续费/扩容：** 升 B；或续用量包（建议 ¥3,000–8,000 / 包，单独条款）。

## B. 工程链路版

**适合：** 中小整机厂、飞控算法团队、试飞组（源码侧）、eVTOL 早期（飞控+适航各一人）。必须 **书面授权 ≤4 个路径**。

**交付**

- 在客户授权目录内，分段完成调用链追踪纪要（**只含路径、函数名、摘要、证据类型**，不含源码正文）
- 最多 **2 次** 正式工作会话（各 ≤2 小时）+ 异步答疑 6 小时上限
- 用量包按 4 周设计上限
- 可选一次失败复盘（仍不写事故责任）

**不交付**

- 超过四个文件的全库搜索  
- 正式符合性声明、UOM 代报、空域/证件申请  
- 修改客户代码、出 mixer 最优设计  
- 把纪要写进客户受控适航包封面（他们可自行引用路径）

**周期：** 4 周（授权延迟不计入 Tokfai 违约）。

**验收标准**

1. 授权四文件均尝试 Read；读不到的写「读不到」及尝试路径  
2. 调用链表四跳齐全或明确 NOT_IN_FILE  
3. 每条结论标注 文件证据 | 工程推断  
4. 无工具记录的断言 = 验收失败项（需重做该段，不另扩范围）

**客户提供：** 授权清单、对接飞控一人、本机环境、禁止投屏目录清单。  
**Tokfai 提供：** 用量、会话、纪要模板填空、推荐模型路由。

**风险边界：** 函数名与教学树不同是正常的，不构成失败。客户拒装 CLI 则本档不生效，可退回 A。涉密目录一经发现终止，已发生用量不退（合同写明）。

**建议报价：** ¥28,000–58,000。  
**续费/扩容：** 加第 5–8 个文件按附录价；或升 C；或月度用量订阅。

## C. 团队协同版

**适合：** 试验室+飞控、集成商（已拿到主机厂授权）、eVTOL 要「链 + 矩阵或日志」两项目。温度=极热。

**交付**

- B 档全部  
- **3 个** 席位（CLI 配置辅导，不共享密钥到群）  
- **第二工作流二选一：** 测试日志解释 **或** 需求–矩阵路径线索（仍非正式符合性）  
- 周例会 6 次以内（各 45 分钟）  
- 期末 2 页边界说明（给适航/质量：什么不是证）

**不交付**

- 不替代委任代表、检测机构、律师  
- 不接第四工作流（申请材料辅助需另签，建议 +¥2–4 万起，本档默认不含）  
- 不做 24×7 值班、不进客户事故调查程序  
- 不承诺并发/多 Agent 审查

**周期：** 6–8 周。

**验收标准**

1. 满足 B 的验收  
2. 第二工作流产出对照表（科目/需求 ID | 路径 | 函数或「找不到」| 证据类型）  
3. 三席位均能独立连上（以客户确认，抽查不看 key）  
4. 例会纪要不含源码正文  

**客户提供：** 授权树、日志或矩阵抽样、质量或适航联络人、席位名单。  
**Tokfai 提供：** 更大用量上限、多席位开通、双工作流陪跑、周例会。

**风险边界：** 专有日志打不开 → 第二工作流改抽可打开样本或降级为仅 B 并按差价退/转用量。模型误摘要不构成责任认定。

**建议报价：** ¥68,000–128,000。  
**续费/扩容：** 年框席位（建议从 3 席、用量封顶谈）；每加一工作流单项报价；不用“无限 Token”。
