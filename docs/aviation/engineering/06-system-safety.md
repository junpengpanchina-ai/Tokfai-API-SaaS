## Core vocabulary

| Term | Role |
| ---- | ---- |
| Hazard | Potential source of harm |
| Failure Condition | Effect of failure(s) on aircraft/ops |
| Severity | Impact class (project/basis dependent) |
| Safety Objective | Acceptable probability/severity target |
| Mitigation | Design/procedure/ops control |
| Verification | Proof mitigation works |
