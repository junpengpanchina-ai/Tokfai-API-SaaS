# 07 — Flight Application Requirements

Primary sources:

- REG-001《无人驾驶航空器飞行管理暂行条例》第二十六–三十一条  
- UOM-001（平台作为执行入口，`INTERPRETATION`）

**“提前一天申请”只是时间规则之一，不是全部要求。**

## 1. Timing rules（FACT）

| Rule | Content | Source |
| ---- | ------- | ------ |
| 一般申请截止 | 拟飞行前1日12时前提出 | Art.26 |
| 一般批准截止 | 飞行前1日21时前作出决定 | Art.26 |
| 常态长期申请 | 固定空域常态飞行可申请长期；仍须飞行前1日12时前备案飞行计划 | Art.26 |
| 紧急任务 | 计划起飞30分钟前申请；起飞10分钟前决定；特别紧急可随时申请 | Art.29 |
| 起飞前确认 | 已批准的，计划起飞1小时前报告预计起飞时刻和准备情况，经确认后方可起飞 | Art.30 |

## 4. “无需飞行活动申请” Decision Table

**核心原则：**

```text
无需飞行活动申请
≠
无需其他任何监管要求
```

| 条件 | 是否无需飞行活动申请 | 仍可能存在的其他 Gate | Source |
| ---- | -------------------: | --------------------- | ------ |
| 微/轻/小在适飞空域内飞行 | 是 | G2 登记；G4 操控规范；G6 保险（视情形）；G7 识别；行为规范（视距等） | Art.31(一) |
| 常规农用作业飞行 | 是 | 农用条件本身；保险/登记等仍按适用条款 | Art.31(二)；Art.11 |
| 警察/海关/应急管理部门辖有无人机，在驻地/训练场/靶场等上方≤真高120 m | 是（但起飞前1小时确认） | 确认程序；其他许可 | Art.31(三) |
| 民用无人机在民用运输机场管制地带执行巡检、勘察、校验等 | 是（定期备案 + 起飞前1小时确认） | 备案；机场相关协调 | Art.31(四) |
| 上述“无需申请”但存在：基站/互联网中继飞行 | **否，回流申请** | G9+G7 | Art.31 第二款(一) |
| 运载危险品或投放物品（常规农用除外） | **否，回流申请** | G10 | Art.31 第二款(二) |
| 飞越集会人群上空 | **否，回流申请** | G10 | Art.31 第二款(三) |
| 在移动交通工具上操控 | **否，回流申请** | G10 | Art.31 第二款(四) |
| 分布式操作或集群飞行 | **否，回流申请** | G5/G10 | Art.31 第二款(五) |
| 微/轻在适飞空域 | 无需特殊通航任务批准文件 | 仍受其他条款约束 | Art.31 末款 |
