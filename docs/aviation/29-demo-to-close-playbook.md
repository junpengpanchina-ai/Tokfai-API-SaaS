## 3. 30 分钟技术版

严格 **segmented**。每段先 Read，再说话。

| 段 | 时间 | 动作 | 过关 |
| -- | ---- | ---- | ---- |
| 准备 | 0–3 | 打开授权目录；念范围约束 | CLI 可见四文件 |
| S1 | 3–8 | Read task 文件 → `attitude_control_entry` | 路径+函数 |
| S2 | 8–14 | 追 `rotor_law_update` 输入/输出名 | 文件证据 vs 推断 |
| S3 | 14–20 | `control_allocation` 虚拟控制→通道 | 无矩阵就 NOT_IN_FILE |
| S4 | 20–25 | `actuator_command_write` | 链闭合 |
| 收口 | 25–30 | 填 SOP 报告模板；约试点 | 无源码纪要 |

技术强调：工具面板必须出现 Read；口头“我读了”不算。  
超时：停在已完成段，仍可成交“部分链+下周续”。

客户自己的树：换文件名，**流程不变**。

## 10. 免费演示 → 付费试点

| 免费（已发生） | 付费试点（要锁） |
| -------------- | ---------------- |
| synthetic 四文件链 | 客户授权目录（仍 ≤4 文件起步） |
| 方法/SOP 讲解 | 每周固定时段 + 用量上限 |
| 公开行业文档 | 对客户纪要中的路径表（无源码） |
| | 可选第二工作流：日志或矩阵（加价项） |

**收费理由（对客户原话）：** 教学树证明能力；你们的构型、日志、矩阵才是项目风险，要用带授权的重复劳动。

**试点成功标准（写入 SOW）：**

```text
1. 在授权四文件内完成分段追踪
2. 每跳有路径+函数+文件证据|推断
3. 无工具记录的结论计为失败项
4. 不包含取证/空域批准
```

**转化信号：** 指定路径、指定对接人、能批试点款、接受 CLI。  
**停止信号：** 只要方案书、要源码礼物、要保证拿证、不授权目录。

扩单顺序：飞控链 → 日志复盘 → 符合性矩阵线索 → UOM 材料辅助。一次只加一项。
