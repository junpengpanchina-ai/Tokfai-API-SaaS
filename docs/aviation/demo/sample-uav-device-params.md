# 样例 — 无人机设备参数表（合成）

```text
SYNTHETIC_DEMO_ONLY
MODEL=TSL-X600（虚构）
USE_CASE=商业电力巡检 / 测绘
P1276-R0
```

**文件形态：** 模拟 Excel 导出为 Markdown  
**版本：** Demo-SW-2.3.1 / 构型 DEMO-CFG-01  

---

## 环境与限值

| 参数 ID | 名称 | 限值 | 单位 | 备注 |
| ------- | ---- | ---- | ---- | ---- |
| ENV-TMAX | 最高工作环境温度 | 45 | °C | 超过需暂停作业 |
| ENV-TMIN | 最低工作环境温度 | -10 | °C | 低于需预热流程 |
| ENV-WMAX | 最大允许风速 | 8 | m/s | 平均风速，阵风另见手册 |
| ENV-ALT | 最大作业海拔 | 3000 | m | 推力按高原包线 |

---

## 能源

| 参数 ID | 名称 | 值 | 备注 |
| ------- | ---- | -- | ---- |
| BAT-CHEM | 电池类型 | 智能锂电包 | — |
| BAT-SOC-RTH | 低电量返航阈值 | 25 | % |
| BAT-DEGR | 循环衰减提示 | 300 次后容量≤80% | 维护手册 p.22（虚构） |

## 导航与通信

| 参数 ID | 名称 | 值 | 备注 |
| ------- | ---- | -- | ---- |
| NAV-GNSS | 主定位 | GNSS+RTK（可选） | 弱信号时见日志事件 |
| LINK-LOS | 视距链路 | 2.4G 图传 | 丢链触发 RTH（见手册 p.40 虚构） |

## 与退回意见对照点（演示）

- 申请书若填 **10 m/s** 风速 → 与本表 **ENV-WMAX=8** 冲突（见 rejection 样例意见 3）。  
- 高温作业需对照 **ENV-TMAX=45**（见 log 样例 temp 字段）。
