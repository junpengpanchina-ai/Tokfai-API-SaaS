## A 档 — 轻量文件诊断

**适合：** 首次合作、只有 1–2 份材料、要看“证据链长什么样”、运营商/集成商先对表。

| 包含 | 不包含 |
| ---- | ------ |
| CLI 安装陪跑（≤4h） | 读客户飞控源码树（默认无） |
| 1–2 份授权 PDF/Excel/驳回页解析 | 四文件完整调用链 |
| 5–15 行 EVIDENCE_ROW | 驳回全套 REMEDIATION 闭环 |
| 1 页风险摘要 + ADVICE | 代报 UOM / 保证通过 |
| 用量包（2 周量级） | 投标技术方案代写 |

**客户提供：** 本机电脑、1–2 文件、对接人。  
**Tokfai 输出：** 轻量证据表 + 边界说明 + 是否升 B 的建议。  
**验收：** CLI 可用；≥3 行 FILE 级 row（或明确 NOT_IN_FILE）；客户确认不托管源码。

**续费：** 升 B；或用量包 ¥3k–8k。

---

## B 档 — 审批/航飞/任务函数复合诊断

**适合：** 申请被退、任务/空域边界乱、要飞控链+材料一致性的整机/飞控/政企项目。

| 包含 | 不包含 |
| ---- | ------ |
| 申请书+手册+驳回（若有）复合解析 | 无限文件扫描 |
| ≤4 飞控源文件调用链（或授权等价路径） | 改代码、签适航 |
| 函数 F3/F5/F7 + R-类分型 | 实时控飞 |
| EVIDENCE_ROW 全表 + REMEDIATION_TASK | 极端环境“突防”方案 |
| [41](./41-customer-deliverable-template.md) L2/L3 报告 | 源码出站存档 |
| 2×2h 会话 + 6h 异步答疑 | |

**客户提供：** 书面授权清单、申请/手册/驳回、≤4 代码路径、可选日志 1 架次。  
**Tokfai 输出：** 材料缺口表、四边界、技术链、整改清单、环境/通信检查表（按实际文件）。  
**验收：** 每条结论有 pointer 或标 cannot_infer；无审批通过承诺句。

**周期：** 4 周（客户补文件延迟不计违约）。

**续费：** 升 C；或月包日志复盘（见下）。

---

## C 档 — 连续项目顾问型交付

**适合：** 多架次作业期、函数 F1–F8 多域、试验+审批并行、eVTOL 早期材料战。

| 包含 | 不包含 |
| ---- | ------ |
| B 档全部 | 驻场代飞、代运营 |
| 3 CLI 席位开通辅导 | 7×24 实时告警 |
| 第二工作流：**日志复盘** 或 **符合性矩阵线索** 二选一 | 正式适航签字 |
| 周会 6×45min | 武器/规避监管内容 |
| 41 模板 L4 全套 + 函数/环境检查表 | 无限 Token |
| 试点期后 **1 次** L5 方法沉淀（无客户正文） | |

**客户提供：** 多文件授权树、架次日志节奏、适航/运行联络人、席位名单。  
**Tokfai 输出：** 可交付给甲方的指针化报告包、飞前/飞后检查表、版本一致性表。  
**验收：** B 验收 + 第二工作流对照表 + 三席位可连网关。

**周期：** 6–10 周。

## 内部报价逻辑

```text
1. 免费 Demo（49）→ 只锁方法与信任
2. 试点 A/B/C → 锁范围与 SUCCESS CRITERIA（指针表，非审批）
3. 续费 → 用量包 + 席位（月）；日志/架次增量
4. 项目制 → C 延长或 enterprise：多机型 SOW、年度用量封顶
```

| 阶段 | 卖什么 | 不卖什么 |
| ---- | ------ | -------- |
| 试点 | 可重复证据链交付 | 结果保证 |
| 月续 | 架次后摘要、版本 drift | 全库 RAG |
| 项目 | 函数+环境+审批复合 SOP | 代客户承担运行责任 |

**加价项（单独列）：** 第 5–8 个代码文件；第二工作流双开；极端环境 E1–E8 专册；加急会话。

**折扣：** 不在电话里折扣；打包写进 SOW。
