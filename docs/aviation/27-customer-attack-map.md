## 0. 怎么用这张图

1. 先定客户属于下面哪一类（可多类，但**当场只打一类切口**）。  
2. 用「最痛 3 卡点」对齐对方原话。  
3. 用「谁最着急」约对的人来看 [29](./29-demo-to-close-playbook.md) 对应时长。  
4. 白嫖信号 ≥2 → **不排技术深潜**，只给公开 SOP 级说明或收口试点报价。  
5. 成交信号 ≥2 → 约 **fixed-file-scope** 演示，不约全库扫描。

全局禁止（所有画像共用）：

```text
不承诺拿证、批空域、代报 UOM
不承诺 Tokfai 执行本地工具或保存源码
不承诺符合 CCAR / GB / 专用条件
不把 synthetic 函数名说成客户机型事实
不输出源码正文、key、Authorization、apiKeyId、canary
```

## 1. 无人机整机厂

**真实业务：** 设计/总装工业或物流/巡检机体；卖飞机+地面站+有限飞控；要过登记、空域、客户验收，中大型还要适航与运行衔接。

| 最痛 3 卡点 | 为何被打回 | 谁最着急 |
| ----------- | ---------- | -------- |
| 飞控/分配/执行器只有少数人能讲清 | 甲方/适航代表问“分配怎么到电机”答不上路径 | 飞控负责 / 总师 |
| 试验/HIL 与代码对不上 | 检测所或客户要追溯，交一堆 PDF 对不上仓库 | 系统工程 / 质量 |
| 客户现场“飞不了”分不清证还是空域 | 合同写了交付日，Gate 仍是红灯 | 项目 / 售后 |

**演示点：** 本机打开 ControlLaw 四文件（或客户指定等价文件），走姿态→分配→执行器路径表。  
**一句话切口：** 「不把代码拷走，当场把姿态入口追到执行器，路径可验收。」  
**禁止承诺：** 保证机体通过客户验收或适航；全库自动找缺陷。  
**成交信号：** 能指定 ≤4 个文件；飞控/系统工程愿意开 Codex CLI；要试点报价而非“先给方案书”。  
**白嫖信号：** 只要架构白皮书/法规对照表；拒绝本机演示；要“把你们验证过的控制律给我们”。

## 2. eVTOL 主机厂

**真实业务：** 载人/载货 eVTOL 取证与试制；TC/PC/AC、专用条件、HIL/试飞包、后续运行人对接。有 TC ≠ 可商业飞。

| 最痛 3 卡点 | 为何被打回 | 谁最着急 |
| ----------- | ---------- | -------- |
| 专用条件/符合性矩阵与软件证据脱节 | 局方/委任代表要 MoC，材料厚但无文件锚点 | 适航工程 |
| 控制律与推进/BMS 耦合说不清 | 专用条件问能量/降级，软件组答“在别的模块” | 飞控+动力联合 |
| 2026 过渡/新设计路径选错 | 把新闻“获适航”当运营权 | 项目/法务 |

**演示点：** 四文件链证明“能读审定相关软件并出追溯摘要”；另用 [25](./25-certification-and-operation-chain.md) 做证件问诊（不代审）。  
**一句话切口：** 「把控制链做成可评审的路径表，材料线索留给你们适航代表，我们不代替局方。」  
**禁止承诺：** 保证 TC/PC/AC；保证赶 2026-11-26 过渡窗；标准适航证口吻。  
**成交信号：** 适航+飞控同时在场；审定包可本机打开；要付费试点写进 WBS。  
**白嫖信号：** 只要竞品证件对照和专用条件解读长文；不让碰任何仓库/矩阵。

## 3. 飞控 / 导航 / 通信 / BMS 供应商

**真实业务：** 卖子系统、算法库、板卡、协议栈；要过主机厂 ICD 验收与问题定位。

| 最痛 3 卡点 | 为何被打回 | 谁最着急 |
| ----------- | ---------- | -------- |
| 接口扯皮（指令进了谁、谁写执行器） | 主机厂集成失败归咎供应商 | 项目 FAE |
| FDIR/丢链/限功率逻辑散落 | 联试超时，日志对不上函数 | 软件负责 |
| 交付文档与代码漂移 | 审计抽检抽到旧函数名 | 质量 |

**演示点：** 在**供应商自己的**交付包或仿真树里追调用链；或与主机厂联席四文件（两边都本机）。  
**一句话切口：** 「下一场联试前，把“谁调用谁”钉在路径上，减少甩锅会。」  
**禁止承诺：** 保证通过主机厂入厂测试；保证通信符合运行识别国标。  
**成交信号：** 下周有联试节点；愿意用自家四个文件演示；采购能谈席位/用量。  
**白嫖信号：** 只要“标准 ICD 模板”；要你们帮看主机厂源码（无授权）。

## 4. 低空运营平台

**真实业务：** 起降点/航线调度、UOM 对接、动态数据、运行控制；卖给政府或运营商。

| 最痛 3 卡点 | 为何被打回 | 谁最着急 |
| ----------- | ---------- | -------- |
| 字段/状态与局方平台对不齐 | 申请失败、动态数据被拒 | 产品+合规 |
| 多机型差异当统一 API | 甲方要“一个平台管所有飞机”失败 | 架构 |
| 运行材料与真实航电能力脱节 | 宣传能飞，飞机侧无对应模块 | 商务被投诉 |

**演示点：** 本机 ICD/接口文档 + 少量适配代码路径；**不要**第一场读飞控核心（除非客户就是飞控）。问诊用 Gate G7/G9。  
**一句话切口：** 「先把平台字段追到机上/文档路径，再谈智能化调度。」  
**禁止承诺：** 代对接 UOM、保证接入通过、保证空域批复。  
**成交信号：** 有具体失败回执（脱敏）；接口人+合规在场；试点=某条字段映射。  
**白嫖信号：** 只要“低空经济政策解读 PPT”；要全套 UOM 对接源码。

## 5. 政企低空项目承建方

**真实业务：** 集成飞手、飞机、平台、场地，向政府/国企交付“能飞的示范”。

| 最痛 3 卡点 | 为何被打回 | 谁最着急 |
| ----------- | ---------- | -------- |
| 合同里程碑 vs 证件/空域红灯 | 验收日到了飞机不能合法飞 | 项目经理 |
| 供应商太多，问题说不清 | 甲方问责找不到责任模块 | PMO |
| 把演示航线当成常态运行 | 首飞后无法持续 | 业主代表 |

**演示点：** 用 [25](./25-certification-and-operation-chain.md) 把“飞不了”拆成 Gate；技术场用**集成包里授权的**少量文件或日志，不做无授权 OEM 源码。  
**一句话切口：** 「验收前先把卡点拆成证、空域、飞机、链路四类，避免开盲盒。」  
**禁止承诺：** 保证示范区批准、保证代运营合格证。  
**成交信号：** 有明确验收日；能拉齐主机厂授权；要付费“缺口清单+本机追溯试点”。  
**白嫖信号：** 要一份可直接投标的技术方案；主体不清还要看所有厂家代码。

## 6. 检测认证 / 试验单位

**真实业务：** 试验、检测、报告、部分符合性证据；吃大纲、记录、一致性。

| 最痛 3 卡点 | 为何被打回 | 谁最着急 |
| ----------- | ---------- | -------- |
| 科目–激励–软件版本对不齐 | 报告被委托方/局方质疑 | 试验室主任 |
| 记录海量，人工翻 | 排期爆 | 试验工程师 |
| 客户临场改构型 | 报告与受试件不一致 | 质量 |

**演示点：** 指定大纲段落 + 日志片段 + 1–2 个源文件（客户授权），做对照表。  
**一句话切口：** 「把科目和代码路径钉在同一张表上，减少报告返工。」  
**禁止承诺：** 出具正式检测结论、替代 CNAS/局方认可。  
**成交信号：** 有积压科目；客户书面授权看文件；按项目/机时买用量。  
**白嫖信号：** 只要自动出正式报告模板；拒绝任何原始记录进本机工具。

## 7. 无人机培训 / 运维公司

**真实业务：** 操控员培训、机队维保、排故、代作业；吃规程、手册、日志，较少自研飞控。

| 最痛 3 卡点 | 为何被打回 | 谁最着急 |
| ----------- | ---------- | -------- |
| 排故靠老师傅 | 客户停飞索赔 | 机务主管 |
| 手册与机载版本不一致 | 培训教错模式 | 教务 |
| 运行申请反复退 | 作业窗口丢掉 | 运行调度 |

**演示点：** 本机手册/检查单/日志（W5/W6/W8）；飞控四文件仅当其确有维修权限与文件。  
**一句话切口：** 「用本机手册和日志做可重复排故摘要，而不是把飞机代码上传网盘。」  
**禁止承诺：** 保证训练合格取证、保证故障定位 100% 正确。  
**成交信号：** 机队有日志规范；要席位给机务；能接受 CLI。  
**白嫖信号：** 只要题库/教案全套；要破解厂家加密日志。

## 8. 跨类速查

| 客户卡在… | 优先画像 | 演示 |
| --------- | -------- | ---- |
| 起飞申请/UOM | 平台 / 承建 / 运维 | 问诊 + 文档字段，非全库飞控 |
| 适航包 | eVTOL / 整机 | 四文件链 + 矩阵线索 |
| 飞控验证 | 整机 / 飞控商 | P1240 形态链 |
| 测试日志 | 试验 / 运维 / 整机 | 日志+少量源 |
| 供应商协同 | 飞控商 / 承建 / 整机 | 调用链路径表 |

真需求：有日期、有文件范围、有决策人、愿本机演示、愿谈试点钱。  
白嫖：只要方案与法规作文、拒工具、拒文件、要源码级礼物。
