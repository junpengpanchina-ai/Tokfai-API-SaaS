3. 缺口清单：按字段列出 `NOT_FOUND` 项。
4. 自操流程模板：把“先确认什么、后提交什么、再看什么结果”写成客户可执行步骤。

**7. 客户明天自操流程**

1. 先确认飞机类别、重量、用途、是否涉及经营性飞行。
2. 核对实名登记是否已完成，登记标志是否可用。
3. 核对操控员资质、培训、考试、执照或操作证书是否齐全。
4. 判断任务是否落入管制空域、临时管制空域或需要审批的特定场景。
5. 准备飞行计划字段：主体、机型、起降点、时间、航线、高度、速度、空域、通信联络、C2 链路、应急处置。
6. 若需要审批，按时提交申请，并等待批准或驳回结果。
7. 起飞前检查无人机状态、电子围栏、通信链路、天气、现场安全边界。
8. 飞行中持续监视动态，按规定报送数据，保留日志和异常记录。
9. 落地后整理审批材料、飞行记录、问题记录、整改项。

**8. 不承诺事项**

1. 不承诺审批一定通过。
2. 不承诺现有材料已经满足全部监管要求。
3. 不承诺缺口字段可以被现有文件补齐。
4. 不承诺 `CHECK` 状态文件的正文结论可直接使用。
5. 不承诺这些规范本身等同于项目落地合规证明。
