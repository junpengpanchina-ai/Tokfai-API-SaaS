## 1. 第一次客户电话怎么问（8 问，≤10 分钟）

按顺序，不要一次全倒：

1. 你们现在是**申请被退**、**联试说不清**，还是**飞完对不上日志**？  
2. 退回或卡点有没有**原文**？（一页 PDF 也行，不用发我）  
3. 飞机是巡检/测绘/电力/物流/政企哪一类？**合法任务**边界写在哪份文件？  
4. 飞控/手册/申请能不能在**你们电脑**上打开？我们不上传网盘。  
5. 有没有书面清单：这次允许看哪几个文件名？  
6. 谁决策试点预算——运行、飞控还是项目？  
7. 你们要的是“聊天懂无人机”，还是“**文件指针表**能上会”？（我们要后者）  
8. 能接受 Codex 本机读文件、Tokfai 只做模型路由吗？

**温度判断：** 有退回原文 + 能本机演示 + 有决策人 → 约 30 分钟。只要“先发资料” → 发公开链接 + 约演示，不写定制方案。

## 2. “客户上传文件”后怎么解释（纠正预期）

客户说“我把文件传给你”：

> 不用传给我们。文件留在你们电脑或内网目录。  
> 我们用 Codex 在你们机器上 Read，纪要里只有**文件名、页码、栏位、函数名**。  
> Tokfai 网关不存你们资料室副本，也不替你们点 UOM 提交。  
> 第一次可以先看**教学飞控目录**证明方法；要接你们真文件，走付费试点并签授权清单。

若客户坚持上传：拒绝收源码包；可收**脱敏后的 1 页退回意见截图**仍建议本机投屏。

## 3. 30 分钟 Demo 时间表

| 分钟 | 动作 | 屏幕 |
| ---- | ---- | ---- |
| 0–3 | 职责分离：CLI 读文件 / Tokfai 路由 | 架构一句 |
| 3–8 | synthetic 四文件分段 Read | 工具面板 + 路径 |
| 8–12 | 填 3 行 EVIDENCE_ROW 样例 | 模板 |
| 12–18 | **若有授权**：1 份申请或手册 1 页 | 真实栏位/页码 |
| 18–22 | 风险 1 条 H + 补件 1 条 | 缺口表 |
| 22–27 | 41 报告目录走一遍 | 免责声明 |
| 27–30 | A/B/C 报价区间 + 48h 要授权清单 | [50](./50-uav-paid-pilot-pricing-and-scope.md) |

无客户文件：12–18 改讲“缺文件时我们只出问诊清单”（[48](./48-real-customer-file-to-evidence-demo.md) D0）。

**禁止：** 全库扫描、贴源码、保证下批过、实时控飞。

## 4. “你们不懂无人机” → “我们懂证据链和函数”

| 客户质疑 | 回应 |
| -------- | ---- |
| 你们不懂飞控 | 我们不替总师设计律。我们证明**读到的路径和函数**能不能写成表，给联试和适航对材料。 |
| 你们不懂行业 | 行业话术人人会。退回意见第 3 句对应哪一页手册，这个要**指针**。 |
| 和大模型有啥区别 | 聊天不上会。我们固定范围、工具 Read、EVIDENCE_ROW，纪要可验收。 |
| 我们要的是能飞 | 能不能飞是运行人和局方。我们能帮**材料别自相矛盾**。 |
| 极端环境你们行吗 | 我们按手册限值和日志字段做**对照**（[46](./46-uav-extreme-environment-commercialization.md)），不做突防。 |

一句收口：

> 无人机我们不在天上替你们飞；我们在**文件和日志里**把函数、栏位、页码钉在一起，减少审批和联试返工。

## 5. 引导进入付费 Pilot

**演示结束 30 秒：**

> 今天免费部分是方法和教学树。  
> 要接你们申请、手册、日志或四个飞控文件，走 **A/B/C 试点**（[50](./50-uav-paid-pilot-pricing-and-scope.md)）。  
> 48 小时内请给：授权文件名清单 + 对接人。  
> 我们发一页 SOW：只读、本机、成功标准=证据表+缺口表，**不包审批通过**。

| 客户状态 | 推档 |
| -------- | ---- |
| 只信方法、无文件 | A |
| 有退回+申请+少量代码 | B |
| 多函数+日志+多席位 | C |

**异议：**

- “先免费做完” → 免费已做完；真文件=付费。  
- “太贵” → 比顾问便宜在**可重复**；先 A 再 B。  
- “要保证过” → 不做；换客户或停。
