## 2. Q&A

### 为什么存在？

条例生效前已有大量中大型存量机；条例第八条将其纳入适航管理。规章溯及力条款 + 公告 + AC 提供衔接路径。`FACT`/`INTERPRETATION`

### 适用于谁？

满足上表全部条件的存量中大型 + 拟特定类运营合格证路径者。`FACT`

### 不适用于谁？

| Not eligible | Why |
| ------------ | --- |
| 微/轻/小 | 条例本就无需适航许可（另有产品质量路径） |
| 2024-01-01 及以后新设计 | 92.303(a) 走正式本章规定 |
| 发生设计更改的存量机 | 失去“不进行设计更改”条件 |
| 不申请特定类运营合格证路径者 | 92.303(b) 挂钩 92.603(a) |
| 仅想“有个证”但无运营场景匹配 | 安全评定绑定特定运行安全水平 |
| 2026-11-26 之后才启动安全评定申请 | AC：不再受理 |

### 需要什么安全评定？

AC-92-AA-2024-01：设计定型证明材料；基于风险的试飞科目（按级别与旋翼/固定翼分章）；安全评定报告；使用限制等。`FACT`（指南结构已读）

### 与运营合格证关系？

过渡特殊适航是为支持**需要运营合格证的特定类运行**而设的适航批准路径；**不是**运营合格证本身。仍需按 CCAR-92 运营评估/颁证。`FACT`/`INTERPRETATION`

### 2026-11-26 后发生什么？

| Item | Official text | Tag |
| ---- | ------------- | --- |
| 不再受理依据安全评定的特殊适航证申请 | AC-92-01 2.4(3) | `FACT` |
| 已按评定取得的特殊适航证有效期最晚不超过该日 | AC-92-01 2.4(1) | `FACT` |
| 若在该日前取得型号合格证，可申请解除有效期限制（需构型差异说明与工作报告清单等） | AC-92-01 2.4(2) | `FACT` |
| 之后存量机如何继续商业运行的完整替代路径清单 | 需回归正式 TC/适航体系等 | `INTERPRETATION`；细节 `UNKNOWN` |
